Mathematical induction.

Tool for proving some claim P(n) holds for all natural numbers n



The induction domino effect:

    ( P(1) ∧ ∀ k (P(k) → P(k+1)) ) → ∀ n P(n) 




What is this saying?
    P(1)? the claim is true for n = 1

    ∀ k (P(k) → P(k+1))? for all k if its for P(k) then its true 
    for P(k+1)



Putting it all together:



English translation?


How will we prove P(1)? chose first element in domain
    show that claim holds for it
(called the BASE CASE)


Inductive step
How will we prove ∀ k (P(k) → P(k+1))? 
    (How would we prove this for-all statements in predicate logic?)
    AllI
    Pick a random individual, k, in my domain
    ImplyI 
    Assume P(k) this is called the inductive hypothesis
    ... try to get P(k+1)

Revisit our example:

We want to prove that for any positive integer n:

    1 + 2 + ... + n = n*(n+1)/2


    the above claim is P(n)




Proof by induction.

Base Case. We must prove the claim holds for the first positive integer n 
n = 1

. we have that the left side of the claim is one and the rights side of the claim is
1(1 + 1)/2 = 1. the two sides are equal so the base case holds.

Inductive step. We assume the inductive hypothesis - that 
    1 + 2 + ... + k = k(k+1)/2
for some fixed positive integer k. We must show that out claim holds for k+1
